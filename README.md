# Py2APK - Python to Android App Converter

Py2APK is a tool that converts Python scripts into installable Android APK files. It supports Kivy and other Python frameworks, enabling developers to easily package Python apps for Android devices.

## Features
- Convert Python scripts to APKs  
- Supports Kivy and other Python frameworks  
- Easy setup and build process  
- Cross-platform compatibility  
- Seamless deployment to Android devices  

## Tech Stack
- **Language:** Python  
- **Build Tools:** Gradle, Android SDK  
- **Framework Support:** Kivy, PyInstaller  
- **Platform:** Android
